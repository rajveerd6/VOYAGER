About Project

Semester 1 Mini Project
This project was completed as part of the MWD (Multimedia & Web Designing) project in the month of December 2025. It showcases the fundamental understanding of HTML, CSS webpage design skills.
Topic of Project
“Solar System Exploration Encyclopedia”
A visually engaging and informative digital encyclopedia covering planets, stars, cosmic structures, and exploration missions — designed with a futuristic space aesthetic.
Guided By
Professor Aditya Sabale Sir
Under his guidance and support, this project was shaped with creative direction and structured development in Prof. Ram Meghe Institute of Technology and Research
Developed On
Designed and coded on Visual Studio Code, utilizing extensions for efficient development.
Technologies Used
The project is built using:
HTML tags for structure, CSS styling for visuals, animations, layout, and theme. Additional styling patterns like flexbox, grid, glow effects, animations, gradients, and orbitron fonts enhance the user experience.
