# 🚀 VOYAGER — Solar System Exploration Guide

> 🌌 A frontend web project created to explore and learn about our Solar System.

## 📖 About

**VOYAGER** is my **first-ever web development project**, built using **HTML and CSS only**.

It provides an educational exploration of our Solar System, covering planets, dwarf planets, the Sun, major regions, the formation and history of the Solar System, and famous space missions.

## 🌍 Contents

* 🪐 All 8 planets of the Solar System
* 🌑 Famous dwarf planets
* ☀️ Information about the Sun
* ☄️ Asteroid Belt
* 🧊 Kuiper Belt
* 🌌 Oort Cloud
* 🌠 Formation & history of the Solar System
* 🚀 Famous space missions

## 🛠️ Technologies

* 🌐 HTML5
* 🎨 CSS3


## 🎯 Project Goal

The main goal of VOYAGER was to combine my interest in **space and astronomy** with my first experience in **frontend web development**, while learning the fundamentals of HTML, CSS, webpage structure, layouts, and UI design.
